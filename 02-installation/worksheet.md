# Worksheet: Installing Docker

## Part 1: Check Understanding

1. Why do most Windows beginners use Docker Desktop?
2. What is the purpose of `docker version`?
3. What is the purpose of `docker info`?
4. What does `docker run hello-world` prove?

## Part 2: Setup Checklist

Mark each item when complete:

- Docker Desktop installed
- Docker Desktop running
- `docker version` works
- `docker info` works
- `docker run hello-world` works
- `docker images` shows `hello-world`

## Part 3: Problem Solving

If `docker` is not recognized, list 3 things you should try.

If Docker Desktop opens but the engine is stopped, list 2 things you should check.

## Part 4: Practice

Run these commands:

```powershell
docker version
docker info
docker run hello-world
docker ps -a
```

Write one sentence about what each command showed you.
