# Nginx CLI Demo

## Purpose

This example gives you a short guided Docker CLI practice session.

## Run

```powershell
./practice-cli.ps1
```

## Expected Output

You should see:

- An Nginx container start successfully
- `docker ps` showing the running container
- `docker logs` output for the container
- `docker inspect` JSON details

## Browser Check

Open:

`http://localhost:8080`

You should see the Nginx welcome page.

## What You Are Learning

- Starting a container
- Listing containers
- Reading logs
- Inspecting container details
- Cleaning up afterward
