# Answer Key: Introduction to Docker

## How to Use This Key

Compare ideas, not exact wording. If your answer is simpler but still correct, that is fine.

## Flow-1 Suggested Answers

1. Docker helps software run more consistently by packaging the application with what it needs.
2. An image is a packaged blueprint used to create containers.
3. A container is a running or stopped instance created from an image.
4. A container is usually lighter than a virtual machine and does not normally include a full guest operating system.

## Flow-2 Answers

- A running instance of an image: Container
- A place where images are stored: Registry
- A text file used to build an image: Dockerfile
- Persistent storage for container data: Volume

## Flow-3 Suggested Answers

1. Example: an image is like a recipe, a sealed lunch box, or a packed toy kit.
2. Example: a container is like the cooked meal, the opened lunch box, or the assembled toy.
3. Example: Docker reduces setup mismatches between developers.
4. Example: Docker makes deployment more predictable because the same packaged app can run in more than one environment.

## Flow-4 Reflection Guide

- Docker helps because it packages the app and its environment together.
- An image is like a prepared blueprint.
- A container is like the running version of that blueprint.
