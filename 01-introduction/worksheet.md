# Worksheet: Introduction to Docker

## Goal

Use this worksheet to prove that you understand the basic Docker story in plain language.

## Before You Start

- Read the lesson once before answering.
- Try to explain ideas in simple words, not memorized definitions.

## Flow-1: Check Core Ideas

1. What problem does Docker try to solve?
2. What is an image?
3. What is a container?
4. What is one difference between a container and a virtual machine?

## Flow-2: Match the Docker Word

Match each description with the correct word.

- A running instance of an image
- A place where images are stored
- A text file used to build an image
- Persistent storage for container data

Words to use:

- Container
- Registry
- Dockerfile
- Volume

## Flow-3: Explain It Like a Beginner Teacher

1. Write one real-life analogy for an image.
2. Write one real-life analogy for a container.
3. Give one reason a team would use Docker during development.
4. Give one reason a team would use Docker during deployment.

## Flow-4: Reflection

Finish these sentences in your own words:

- Docker helps because...
- An image is like...
- A container is like...
