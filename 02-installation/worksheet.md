# Worksheet: Installing Docker

## Goal

Use this worksheet to confirm that you can install Docker and verify that it is actually working.

## Before You Start

- Review the installation lesson first.
- If Docker is installed, run the commands yourself while answering.

## Flow-1: Quick Check

1. What is the difference between Docker Engine and Docker Desktop?
2. Why do most Windows beginners use Docker Desktop?
3. What command shows Docker version information?
4. What command runs the tiny beginner test container?

## Flow-2: Command Practice

Write the commands for these tasks:

1. Show Docker version information.
2. Show Docker environment details.
3. Run the `hello-world` container.
4. List all containers, including stopped ones.

## Flow-3: Troubleshooting Check

What would you check if:

1. The `docker` command is not recognized?
2. Docker Desktop opens but the engine does not start?
3. `hello-world` does not run correctly?

## Flow-4: Reflection

Write 2 to 4 sentences describing how you would help a friend verify that Docker is installed correctly.

## Part 2: Setup Checklist

- Docker Desktop installed
- Docker Desktop running
- `docker version` works
- `docker info` works
- `docker run hello-world` works
- `docker images` shows `hello-world`

```powershell

```
