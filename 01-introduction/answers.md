# Answer Key: Introduction to Docker

## Part 1 Suggested Answers

1. Docker helps software run more consistently by packaging the app with what it needs.
2. An image is a packaged blueprint used to create containers.
3. A container is a running or stopped instance of an image.
4. A container is usually lighter than a virtual machine and does not normally include a full guest OS in the same way.

## Part 2 Answers

- A running instance of an image: Container
- A place where images are stored: Registry
- A text file used to build an image: Dockerfile
- Persistent storage for container data: Volume

## Part 3 Suggested Answers

1. Example: an image is like a recipe or sealed lunch box.
2. Example: a container is like the cooked meal or opened lunch.
3. Example: it reduces "works on my machine" problems.
4. Example: it makes deployment more predictable.
