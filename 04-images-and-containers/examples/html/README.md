# Static HTML Content

## Purpose

This folder contains the static page served by the Nginx container in the images-and-containers example.

## Expected Output

When the container is running and the folder is mounted into Nginx, opening the example URL should show:

- A heading that says "Hello from a Docker example"
- A short paragraph explaining that port mapping works

## What You Are Learning

- The image provides the web server
- The mounted HTML files provide the page content
- The running container serves that content in the browser
